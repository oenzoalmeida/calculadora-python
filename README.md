# Calculadora com Interface Gráfica em Python

Projeto desenvolvido originalmente durante o terceiro semestre da graduação e posteriormente aprimorado com uma interface gráfica moderna.

A aplicação permite realizar operações matemáticas básicas por meio de uma interface interativa desenvolvida com Python e Tkinter.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Cálculo de porcentagem
- Alteração de sinal positivo e negativo
- Suporte a números decimais
- Tratamento de divisão por zero
- Histórico da última operação
- Suporte ao teclado
- Interface gráfica em tema escuro
- Botões com efeito visual ao passar o mouse

## Atalhos do teclado

- `0 a 9`: inserir números
- `+`: soma
- `-`: subtração
- `*`: multiplicação
- `/`: divisão
- `Enter`: calcular resultado
- `Backspace`: apagar último dígito
- `Esc` ou `Delete`: limpar calculadora
- `,` ou `.`: inserir número decimal

## Como executar

1. Instale o Python 3.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto.
4. Execute o arquivo `main.py`.

Pelo terminal:

```bash
python main.py
```

No Windows, também pode ser utilizado:

```bash
py main.py
```
